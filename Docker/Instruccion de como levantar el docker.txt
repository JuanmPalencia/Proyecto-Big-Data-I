============================================================
  GTP (Green Turning Point) — Cómo levantar Docker
============================================================

REQUISITOS:
  - Docker Desktop instalado y corriendo
  - Cuenta Google Earth Engine en gtpuem23 o la tuya

------------------------------------------------------------
PASO 1 — Levantar la infraestructura base
------------------------------------------------------------
Desde la carpeta Docker/:

  docker compose up -d

Esto levanta:
  - gtp-namenode      → HDFS NameNode   (http://localhost:9870)
  - gtp-datanode      → HDFS DataNode   (http://localhost:9864)
  - gtp-hive-metastore-db  → PostgreSQL interno de Hive
  - gtp-hive-metastore     → Hive Metastore Thrift (puerto 9083)
  - gtp-mariadb       → MariaDB serving layer (localhost:3306)

Esperar ~30-60 segundos a que todo esté listo.
Verificar en http://localhost:9870 que el NameNode está en modo Active.

------------------------------------------------------------
PASO 2 — Autenticar Google Earth Engine (solo primera vez)
------------------------------------------------------------
  docker compose run --rm etl earthengine authenticate

  Esto abre el navegador → acepta → pega el token.
  Las credenciales quedan en el volumen Docker 'gee_credentials'
  y persisten entre reinicios (no hay que repetirlo).

  Verificar que funciona:
  docker compose run --rm etl python -c "import ee; ee.Initialize(project='gtpuem23'); print(ee.Image('USGS/SRTMGL1_003').getInfo()['type'])"

------------------------------------------------------------
PASO 3 — Ejecutar el ETL (extracción de datos)
------------------------------------------------------------
  docker compose --profile etl run --rm etl

  Genera CSVs en Docker/data/DatosProcesados/
  Puede tardar horas (descarga de GEE, OECD, InvestEU...).

  Para ejecutar solo una fuente concreta:
  docker compose --profile etl run --rm etl python ETL/script/Sentinel-2_extract.py

------------------------------------------------------------
PASO 4 — Ejecutar el pipeline BBDD + ML
------------------------------------------------------------
  docker compose --profile pipeline run --rm pipeline

  Orden: Bronze → Silver → Gold → K-Means → EKC → XGBoost → Prophet → MariaDB

  Para ejecutar solo partes:
    Solo ingestión (sin ML):
    docker compose --profile pipeline run --rm pipeline python BBDD/run_pipeline.py --only-ingest

    Solo modelos (datos ya en HDFS):
    docker compose --profile pipeline run --rm pipeline python BBDD/run_pipeline.py --only-models

    Solo exportar a MariaDB:
    docker compose --profile pipeline run --rm pipeline python BBDD/run_pipeline.py --only-export

    Dry-run (ver comandos sin ejecutar):
    docker compose --profile pipeline run --rm pipeline python BBDD/run_pipeline.py --dry-run

------------------------------------------------------------
PASO 5 — Levantar la API Flask
------------------------------------------------------------
  docker compose --profile api up -d api

  Acceder en: http://localhost:5000
  Endpoints: /api/ranking, /api/city/<code>, /api/opportunities,
             /api/clusters, /api/summary

------------------------------------------------------------
COMANDOS ÚTILES
------------------------------------------------------------
  Ver logs en tiempo real:
    docker compose logs -f pipeline

  Ver estado de todos los contenedores:
    docker compose ps

  Parar todo:
    docker compose down

  Parar y borrar volúmenes (HDFS + MariaDB — DESTRUYE DATOS):
    docker compose down -v

  Acceder a HDFS desde línea de comandos:
    docker exec -it gtp-namenode hdfs dfs -ls /user/gtp/

  Acceder a MariaDB:
    docker exec -it gtp-mariadb mariadb -u bd_rvm_gtp -pSol2026A bd_rvm_gtp

  Reconstruir imagen tras cambios en código:
    docker compose build
